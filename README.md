# 🧠 JavaScript Quiz App

A modern and interactive quiz application built with **HTML, CSS, Bootstrap, and JavaScript**. Test your JavaScript knowledge with multiple-choice questions and a countdown timer.

## ✨ Features
- 🎯 Multiple-choice questions
- ⏱️ 30-second countdown timer
- 🔄 Automatic question navigation
- 📊 Final score calculation
- 📝 Correct answers and selected answers summary
- 📱 Responsive and clean UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 🚀 Getting Started
1. Clone this repository:

 git clone https://github.com/bhoomisadhvani/js_quiz_app.git
 
2. Open the project folder.
3. Run index.html in your browser.
